# Inventario
É um código desenvolvido com o objetivo do usuário acessar seu inventário (minecraft) de forma rápida e eficiente para gerenciar seus itens!

Qual o objetivo da atividade?
 • Aprimorar técnicas da lógica de programação e 
técnicas de análise de design para telas interativas 
com o usuário.
 • Sistemas como bancários e e-commerce, utilizam 
esse tipo de funcionalidade para guardar dados 
dos usuários. Isso é importante, pois através dessa 
funcionalidade permite manter dados registrados 
para futuras alterações do mesmo.

Quais ferramentas foram utilizadas?
 • VSCODE para a execução do HTML, CSS e PHP; 
Bootstrap para a criação de botões interativos. 
Bootstrap é simples e objetivo ao usá-lo.
 • O Layout foi pensado em um cabeçalho e corpo, 
ou seja, 2 linha e 1 coluna.

Qual o passo a passo para acessar?
 Qual a hierarquia de pastas?
 • Fazer login com usuário e senha, adicionar e 
gerenciar seu inventário!
